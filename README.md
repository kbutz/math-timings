# Math Timings

A playful, browser-based math practice game created with Alice for school Math Timings.

## Getting started

Requires Node.js and npm.

```bash
npm ci
npm run dev
```

Open the local URL printed by Vite.

## Testing and building

```bash
npm test
npm run build
```

The production build is written to `dist/`.

## Project structure

- `src/` — application, math practice logic, UI, 3D scene, and sound
- `public/` — models and web app manifest
- `tests/` — automated tests
- `docs/` — design specifications and implementation plans

## Notes

This project uses Vite, TypeScript, Three.js, and Vitest. Dependencies and generated builds are intentionally excluded from version control.
